# URS — 전자로그북 기록 시스템 v2 (Electronic Logbook)

## 1. 사용 목적

장비의 사용기록을 수기기록에서 전자기록으로 전환하는 시스템

구현방법: 웹 (브라우저 단독 실행)

> v2 비고: 파일럿(v1)과 동일한 요구사항을 유지하되, 회사망 제한 환경에서도 동작하도록
> 외부 라이브러리 의존성 없는 단일 파일 구조로 재구축한다.

## 2. 기능 요구사항

1. 로그인 기능이 있어야 한다. (시스템은 ID/PW 형태로 로그인)
2. 사용 로그를 남길 장비의 선택 또는 입력이 가능해야 한다.
3. 로그 기록에는 작업 시작 시간, 종료 시간, 장비사용목적 입력이 가능하여야 한다.
4. 로그인한 사용자가 사용 로그를 남겼을 때 전자서명 되어야 한다. (전자서명은 서명자와 현재 날짜·시간이 표시되어야 한다.)
5. 입력한 사용 로그 기록은 삭제 및 수정이 불가능하여야 한다.
6. 전자로그북은 출력할 수 있어야 하며 출력물은 PDF 형태여야 한다.
7. 전자로그북 출력물은 출력시간을 (YYYY-MM-DD HH:MM:SS 형태로) 표시하여야 한다.
8. 전자로그북 이력은 조회가 가능하여야 하며, 필터링 기능(장비별, 날짜별, 작성자별)을 지원하여야 한다.
9. 로그인/로그아웃 이력 및 로그북 작성 이력에 대한 감사추적이 가능해야 한다.
10. 모든 웹브라우저(표준 HTML5 지원 브라우저)에서 사용 가능하여야 한다.
11. 자동 로그아웃을 지원해야 하며, 자동 로그아웃 시간을 설정할 수 있어야 한다.
12. 계정에 대한 정책(패스워드 변경 주기, 복잡성)을 설정할 수 있어야 한다.
13. 계정을 생성할 수 있어야 하며, 권한은 2가지(Manager, Operator)로 나뉜다.
14. Manager 권한은 임시로 1개 생성하며, Manager는 Operator 계정을 생성할 수 있다.
15. Operator는 장비 사용 로그를 남길 수 있고, 장비사용 기록서를 출력할 수 있다.
16. 시스템은 현재 시간을 표시하여야 하고 한국표준시(KST)를 나타내야 한다.
