## 1. 프로젝트 개요

URS 16개 항목의 공급업체 평가 관리 시스템을 단일 HTML 파일(`sem.html`)로 구현한다.

> **품질 기준**: 목업이 아닌 실제 구동 가능한 고품질 완성품. 핵심 검증 포인트는 **다항목 점수 → 등급 자동판정의 정확성**과 **승인 전 ASL 미반영 통제**다.

### 산출물 (4종)

| # | 파일 | 용도 |
|:-:|---|---|
| 1 | `URS.md` | 사용자 요구사항 (16개 항목) |
| 2 | `FDS.md` | 기능 설계 명세서 (등급 판정 규칙, 추적 매트릭스) |
| 3 | `구현계획서.md` | **본 문서** |
| 4 | `sem.html` | 실습 대상 웹 애플리케이션 (단일 파일 SPA) |

---

## 2. 아키텍처 요약

- 단일 파일 SPA, 순수 HTML/CSS/JS, **외부 의존성 0**, localStorage (prefix `sem:`)
- Starbucks 디자인 시스템 (기존 시스템과 동일 표준)
- 핵심 도메인: **다항목 평가 + 실시간 등급 판정 + 승인 워크플로우(e-Sig) + ASL + 재평가 주기**

---

## 3. 구현 단계 (4 Stage)

### S1. 문서 작성 — URS / FDS / 구현계획서
### S2. sem.html — 골격 + 인증 + 공급업체 마스터 + 평가 기준 관리
### S3. sem.html — 평가 수행(실시간 등급 판정) + 승인 워크플로우 + 수정 이력
### S4. sem.html — ASL/평가 보고서 출력 + 재평가 현황 + 감사추적 + 계정/설정

|:-:|:-:|---|

| **VS-05** | 5 | qa1이 공급업체 선택 → 5개 항목 점수 입력 + 평가 의견 입력 → DRAFT 저장 |
| **VS-06** | 6 | (1) 점수 합계 92 → "A 등급" 실시간 표시 (2) 합계 75 → "B 등급" (3) 합계 45 → "부적합" (4) 항목 배점 초과 입력 차단 |
| **VS-07** | 7 | (1) DRAFT/SUBMITTED 평가는 ASL에 미반영 (2) 승인 완료 시 ASL에 업체와 등급 표시 (3) 부적합 등급은 ASL에서 제외 |
| **VS-08** | 8 | manager1이 승인 시 비밀번호 재입력 → 틀리면 차단, 맞으면 승인자/일시 기록 |
| **VS-09** | 9 | APPROVED 평가 → 수정 버튼 비활성 + "승인 완료" 배지 |

| **VS-12** | 12 | ASL 출력 → 등급 A/B/C 업체만 표시, 차기 평가 예정일 포함, 출력자/일시 표시 |
| **VS-13** | 13 | (1) A등급 승인 → 차기 평가일 = 평가일 + 36개월 (2) 재평가 현황에서 도래 임박(60일)/경과 분류 확인 |
| **VS-14** | 14 | 감사추적에 평가 작성/제출/승인/출력 이벤트 기록 + CSV 내보내기 |
