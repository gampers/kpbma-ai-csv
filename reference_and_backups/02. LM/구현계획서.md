# 구현계획서 — 교육 이수 관리 시스템 (LM)

> CSV 교육용 단일 페이지 웹 애플리케이션 구현 계획
> 작성일: 2026-06-03 | 버전: 1.0 | 작성자: 교육팀

---

## 1. 프로젝트 개요

### 1.1 목적

URS(16개 항목)에 정의된 교육 이수 관리 시스템(LM)을 **브라우저 단독 실행 가능한 단일 HTML 파일**로 구현하여 CSV 교육 실습에 사용한다. 본 문서는 FDS와 분리되어 **구현 작업의 절차/검증 방법**을 정의한다.

> **품질 기준**: 본 시스템은 목업(Mock-up)이 아니라 **실제 구동 가능한 고품질 완성품**이다. 모든 기능이 동작하고, 디자인·UX가 상용 SW에 준하며, 교육생이 현업 레퍼런스로 활용 가능한 수준을 목표로 한다.

### 1.2 산출물 (4종)

| # | 파일 | 용도 |
|:-:|---|---|
| 1 | `URS.md` | 사용자 요구사항 명세서 (16개 항목) |
| 2 | `FDS.md` | 기능 설계 명세서 (URS↔FDS 추적 매트릭스 포함) |
| 3 | `구현계획서.md` | **본 문서** — 구현 단계, 검증, 리스크 |
| 4 | `lm.html` | 실습 대상 웹 애플리케이션 (단일 파일 SPA) |

## 2. 시스템 아키텍처 요약

- **유형**: Single Page Application (SPA), 해시 라우터 기반
- **기술 스택**: 순수 HTML5 + CSS3 + JavaScript (ES2017+) — **외부 의존성 0**
- **저장소**: 브라우저 `localStorage` (네임스페이스 prefix `lm:`)
- **빌드/배포**: 없음 — `lm.html` 파일을 브라우저에서 열기만 하면 동작
- **인쇄**: `window.print()` + `@media print` 스타일시트로 이수증·교육이력서 출력
- **디자인**: Starbucks 디자인 시스템 (웜 크림 캔버스, 4단계 그린, 50px 필 버튼, 12px 카드)

## 3. 구현 단계 (5 Stage)

### S1. 문서 작성 — URS.md / FDS.md
- 16개 URS 항목, 12개 절 FDS, URS↔FDS 추적 매트릭스 16행

### S2. 문서 작성 — 구현계획서.md (본 문서)
- 5 Stage + VS-01~16 검증 시나리오 1:1 매핑

### S3. lm.html — 골격 + 인증 + 라우터 + 마스터 관리
- HTML 골격 + CSS 테마 (Starbucks 디자인 시스템)
- Storage helper, 시드 데이터 자동 주입 (계정 3종, 과정 3종, 임직원 4명)
- 로그인/로그아웃/자동 로그아웃, 해시 라우터 + 역할별 라우트 가드
- 역할별 사이드 내비 + 대시보드 (현황 카드)
- 교육과정 관리, 임직원 관리 (ADMIN)

### S4. lm.html — 평가 입력 / 자동판정 / 워크플로우 / 이수증 / 이력서
- 이수 평가 입력 폼 (5필드 필수 검증, 실시간 자동판정 미리보기)
- 내 작성건 / 승인 대기 목록, 결재 액션 (제출/승인 e-Sig/반려)
- 수정 사유 모달 + RecordHistory, 승인 후 잠금
- 이수증 발행 (문서번호 부여) + 인쇄 양식, 교육이력서 조회 + 인쇄 양식

### S5. lm.html — 재교육 현황 + 감사추적 + 계정/환경설정 + 백업
- 재교육 현황 (유효/임박/만료 분류), 대시보드 경고 카드
- 감사추적 화면 + 필터 + CSV 내보내기
- 계정 관리, 환경설정 (자동 로그아웃 시간, 백업 시각, 회사명)
- 멱등 자동 백업 + 수동 백업/가져오기/데이터 리셋

## 5. 배포 / 실행 방법

1. `lm.html` 더블클릭 → 기본 브라우저(Chrome/Edge)에서 열림
2. 시드 계정으로 로그인:
   - **관리자**: `admin` / `admin`
   - **교육담당자**: `trainer1` / `1234`
   - **QA승인자**: `qa1` / `1234`
3. 데이터 초기화: 환경설정 → "데이터 리셋"

> 모바일 브라우저는 지원하지 않는다 (인쇄 다이얼로그 호환성).
