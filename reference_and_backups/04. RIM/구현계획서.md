# 구현계획서 — 시약/표준품 재고 관리 시스템 (RIM)

> CSV 교육용 단일 페이지 웹 애플리케이션 구현 계획
> 작성일: 2026-06-03 | 버전: 1.0 | 작성자: 교육팀

---

## 1. 프로젝트 개요

URS 16개 항목의 시약/표준품 재고 관리 시스템을 단일 HTML 파일(`rim.html`)로 구현한다.

> **품질 기준**: 목업이 아닌 실제 구동 가능한 고품질 완성품. 특히 **수불 정합성**(잔량 계산의 정확성)이 이 시스템의 핵심 검증 포인트다.

### 산출물 (4종)

| # | 파일 | 용도 |
|:-:|---|---|
| 1 | `URS.md` | 사용자 요구사항 (16개 항목) |
| 2 | `FDS.md` | 기능 설계 명세서 (수불 무결성 설계, 추적 매트릭스) |
| 3 | `구현계획서.md` | **본 문서** |
| 4 | `rim.html` | 실습 대상 웹 애플리케이션 (단일 파일 SPA) |

---

## 2. 아키텍처 요약

- 단일 파일 SPA, 순수 HTML/CSS/JS, **외부 의존성 0**, localStorage (prefix `rim:`)
- Starbucks 디자인 시스템 (LM/ELB/COA v2와 동일 표준)
- 핵심 도메인 로직: **append-only 수불 기록 + 잔량 자동 계산 + 유효기간 통제 + 폐기 e-Sig**

---

## 3. 구현 단계 (4 Stage)

### S1. 문서 작성 — URS / FDS / 구현계획서
### S2. rim.html — 골격 + 인증 + 품목 마스터 + 시드 데이터
### S3. rim.html — 입고 / 사용 기록(잔량 계산) / 폐기 워크플로우
### S4. rim.html — 재고 현황·수불부 출력 + 감사추적 + 계정/설정

## 4. 검증 시나리오 (URS ↔ VS 1:1)

| ID | URS | 시나리오 |
|:-:|:-:|---|
| **VS-01** | 1 | `rim.html` 실행 → 잘못된 비밀번호 차단(LOGIN_FAIL 감사) → `qc1`/`1234` 로그인 성공 |
| **VS-02** | 2 | admin으로 신규 계정(MANAGER) 생성 → 해당 계정 로그인 시 폐기 승인 메뉴만 표시, 입고/사용 메뉴 비표시 |
| **VS-03** | 3 | admin이 품목 등록(품목코드/품명/제조사/규격/보관조건/단위) → qc1은 조회만 가능 |
| **VS-04** | 4 | qc1이 입고 등록(품목, Lot, 수량 500, 유효기간) → 입고자/일시 자동 기록, 재고 현황에 잔량 500 표시 |
| **VS-05** | 5 | 사용 기록에서 Lot 선택 → 현재 잔량 500 표시 → 사용량 30 입력 → "사용 후 잔량 470" 실시간 미리보기 → 저장 → 잔량 470 |
| **VS-06** | 6 | 잔량 470인 Lot에 사용량 500 입력 → 저장 차단 + "잔량을 초과할 수 없습니다" 오류 |
| **VS-07** | 7 | 저장된 입고/사용 기록에 수정/삭제 버튼 없음. 수불부에서 전자서명(기록자, 일시) 확인 |
| **VS-08** | 8 | 유효기간을 20일 후로 입력한 Lot → "만료 임박" 배지 / 어제로 입력한 Lot → "만료" 배지 + 대시보드 경고 카드 집계 |
| **VS-09** | 9 | 만료된 Lot 선택 시 사용량 입력 불가 (선택 목록에서 차단 또는 저장 차단) |
| **VS-10** | 10 | qc1이 폐기 요청(사유 입력) → manager1 로그인 → 폐기 승인(비밀번호 재입력) → Lot 상태 DISPOSED, 잔량 0 |
| **VS-11** | 11 | 재고 현황 보고서 출력 → 출력자/출력일시(YYYY-MM-DD HH:MM:SS) 표시, 전체 Lot의 잔량·상태 표 포함 |
| **VS-12** | 12 | 특정 품목의 수불부 출력 → 입고→사용→폐기 이력이 시간순으로 표시, 각 행의 거래 후 잔량(balanceAfter)이 연속적으로 일치 |
| **VS-13** | 13 | 감사추적에 RECEIPT/USE/DISPOSAL/LOGIN 이벤트 기록, CSV 내보내기 동작 |
| **VS-14** | 14 | 자동 로그아웃 1분 설정 → 1분 무활동 → 자동 로그아웃 |
| **VS-15** | 15 | 입고 등록에서 수량 누락 → 저장 차단 + 해당 필드 오류 표시 |
| **VS-16** | 16 | 동일 품목에 동일 Lot 번호로 재입고 시도 → 저장 차단 + "중복된 Lot 번호" 오류 |

## 5. 배포 / 실행

1. `rim.html` 더블클릭
2. 시드 계정: **관리자** `admin`/`admin` · **QC담당자** `qc1`/`1234` · **QC책임자** `manager1`/`1234`
3. 시드 품목 4종 + 상태별 Lot (유효/임박/만료) 자동 주입
