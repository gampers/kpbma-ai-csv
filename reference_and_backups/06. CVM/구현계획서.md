# 구현계획서 — 세척 검증 결과 관리 시스템 (CVM)

> CSV 교육용 단일 페이지 웹 애플리케이션 구현 계획
> 작성일: 2026-06-03 | 버전: 1.0 | 작성자: 교육팀

---

## 1. 프로젝트 개요

URS 16개 항목의 세척 검증 결과 관리 시스템을 단일 HTML 파일(`cvm.html`)로 구현한다.

> **품질 기준**: 목업이 아닌 실제 구동 가능한 고품질 완성품. 핵심 검증 포인트는 **포인트별 자동판정과 전체 판정(AND 조건)의 정확성**, **부적합 시 사유·조치 강제**다.

### 산출물 (4종)

| # | 파일 | 용도 |
|:-:|---|---|
| 1 | `URS.md` | 사용자 요구사항 (16개 항목) |
| 2 | `FDS.md` | 기능 설계 명세서 (판정 규칙, 추적 매트릭스) |
| 3 | `구현계획서.md` | **본 문서** |
| 4 | `cvm.html` | 실습 대상 웹 애플리케이션 (단일 파일 SPA) |

---

## 2. 아키텍처 요약

- 단일 파일 SPA, 순수 HTML/CSS/JS, **외부 의존성 0**, localStorage (prefix `cvm:`)
- Starbucks 디자인 시스템 (기존 시스템과 동일 표준)
- 핵심 도메인: **계획(샘플링 포인트·허용기준) → 포인트별 결과 입력 → 자동판정(포인트+전체) → 부적합 처리 → QA 승인(e-Sig) → 보고서**

---

## 3. 구현 단계 (4 Stage)

### S1. 문서 작성 — URS / FDS / 구현계획서
### S2. cvm.html — 골격 + 인증 + 설비 마스터 + 검증 계획 등록
### S3. cvm.html — 결과 입력(포인트별 실시간 판정) + 부적합 처리 + 승인 워크플로우
### S4. cvm.html — 보고서 출력 + 설비별 이력 + 감사추적 + 계정/설정

---

## 4. 검증 시나리오 (URS ↔ VS 1:1)

| ID | URS | 시나리오 |
|:-:|:-:|---|
| **VS-01** | 1 | `cvm.html` 실행 → 잘못된 비밀번호 차단 → `val1`/`1234` 로그인 성공 |
| **VS-02** | 2 | admin이 신규 QA 계정 생성 → 해당 계정은 승인 메뉴만 표시, 계획/결과 입력 메뉴 비표시 |
| **VS-03** | 3 | admin이 설비 등록(설비번호/설비명/재질) → 중복 설비번호 차단 |
| **VS-04** | 4 | val1이 검증 계획 등록 — 설비, 이전/차기 제품, SOP, 스왑법, 포인트 4개 추가, 허용기준 10 µg/swab |
| **VS-05** | 5 | val1이 계획 선택 → 포인트별 결과값 입력 (소수점 둘째 자리, 예: 3.25) |
| **VS-06** | 6 | (1) 결과 8.50 입력 → 해당 포인트 "적합" 실시간 표시 (2) 결과 12.00 → "부적합" (3) 결과 10.00(경계값) → "적합" |
| **VS-07** | 7 | (1) 4개 포인트 모두 적합 → 전체 판정 "적합" (2) 1개만 부적합 → 전체 판정 "부적합" |
| **VS-08** | 8 | 전체 부적합 상태에서 저장 시도 → 부적합 사유/조치 미입력이면 차단, 입력 후 저장 가능 |
| **VS-09** | 9 | (1) DRAFT/SUBMITTED 결과는 보고서 출력 불가 (2) qa1 승인(비밀번호 재입력) 후 출력 가능 |
| **VS-10** | 10 | APPROVED 결과 → 수정 버튼 비활성 + "승인 완료" 배지 |
| **VS-11** | 11 | DRAFT 결과값 수정 + 사유 입력 → 수정 이력 before/after 기록, 판정 재계산 |
| **VS-12** | 12 | 승인된 결과의 보고서 출력 → 포인트별 결과·판정 표, 전체 판정, 시험자/승인자, 출력자/출력일시 표시 |
| **VS-13** | 13 | 설비별 이력에서 GR-101 선택 → 해당 설비의 모든 검증 수행 이력(계획·결과·판정) 시간순 표시 |
| **VS-14** | 14 | 감사추적에 계획 등록/결과 작성/승인/출력 이벤트 기록 + CSV 내보내기 |
| **VS-15** | 15 | 자동 로그아웃 1분 설정 → 1분 무활동 → 자동 로그아웃 |
| **VS-16** | 16 | 결과 입력에서 포인트 하나라도 값 누락 시 저장 차단 + 해당 칸 오류 표시 |

## 5. 배포 / 실행

1. `cvm.html` 더블클릭
2. 시드 계정: **관리자** `admin`/`admin` · **밸리데이션담당자** `val1`/`1234` · **QA승인자** `qa1`/`1234`
3. 시드 설비 3대 + 검증 계획 1건 자동 주입

## 6. 리스크 및 완화책

| # | 리스크 | 영향 | 완화책 |
|:-:|---|:-:|---|
| R1 | 부동소수점 비교 오차 (10.00 vs 10.000001) | High | 결과값·허용기준을 소수점 둘째 자리로 정규화 후 비교 |
| R2 | 부적합 기록 은폐 시도 | High | 부적합도 승인 대상 (기록 보존), 감사추적 기록 — 교육 토론 주제 |
| R3 | 평문 비밀번호 | High | 교육 한정 명시 |
| R4 | localStorage 손실 | Medium | 보고서 PDF 출력 권고 |
