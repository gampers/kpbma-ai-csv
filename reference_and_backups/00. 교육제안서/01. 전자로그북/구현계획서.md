# 전자로그북 기록 시스템 - 구현계획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 시스템명 | 전자로그북 기록 시스템 (Electronic Logbook System) |
| 목적 | 장비 사용기록을 수기기록에서 전자기록으로 전환 |
| 구현방식 | 순수 HTML + CSS + JavaScript (설치 불필요) |
| 데이터 저장 | localStorage (브라우저 내장 저장소) |
| 실행 방법 | 브라우저에서 HTML 파일 직접 열기 |

---

## 2. URS 대비 구현 매핑

| URS# | 요구사항 | 구현 방법 | 구현 파일 |
|------|----------|-----------|-----------|
| 1 | ID/PW 로그인 | localStorage에 계정 저장, 로그인 화면 구현 | index.html |
| 2 | 장비 선택/입력 | 장비 목록 드롭다운 + 직접입력 기능 | logbook.html |
| 3 | 시작/종료시간, 사용목적 입력 | 입력 폼 (datetime-local, textarea) | logbook.html |
| 4 | 전자서명 (날짜/시간 표시) | 기록 저장 시 사용자ID + 현재 날짜시간 자동 기록 | logbook.html |
| 5 | 기록 삭제/수정 불가 | 저장된 기록에 수정/삭제 버튼 미제공, 읽기 전용 | logbook.html |
| 6 | PDF 출력 | jsPDF 라이브러리 활용 PDF 생성 | logbook.html |
| 7 | 출력시간 표시 (YYYY-MM-DD HH:MM:SS) | PDF 헤더/푸터에 출력시간 자동 삽입 | logbook.html |
| 8 | 이력 조회 + 필터링 | 장비별, 날짜별, 작성자별 필터링 UI | history.html |

| 10 | 모든 브라우저 지원 | 표준 HTML5/CSS3/ES6 사용 | 전체 |
| 11 | 자동 로그아웃 + 시간 설정 | 비활동 감지 타이머, 설정 화면에서 시간 변경 | app.js |
| 12 | 패스워드 정책 (주기, 복잡성) | 설정 화면에서 정책 관리, 비밀번호 변경 시 검증 | settings.html |
| 13 | 계정 생성, 권한 2종 | Manager / Operator 역할 구분 | admin.html |
| 14 | Manager 계정 1개 (임시), Operator 생성 가능 | 초기 Manager 계정 내장, 계정관리 화면 | admin.html |
| 15 | Operator: 로그 작성 + 기록서 출력 | 권한별 메뉴 표시 제어 | logbook.html |
| 16 | 현재 시간 표시 (KST) | 상단바에 실시간 시계 표시 | app.js |

## 4. 화면별 구현 상세

### 4.1 로그인 화면 (index.html)
- ID / PW 입력 필드
- 로그인 버튼
- 로그인 실패 시 오류 메시지 표시
- 로그인 성공 시 → dashboard.html 이동
- 로그인 이벤트 감사추적 기록

### 4.2 대시보드 (dashboard.html)
- 상단바: 시스템명, 현재시간(KST), 로그인 사용자 정보, 로그아웃 버튼
- 메뉴 네비게이션 (권한별 표시)
  - **공통**: 로그 기록, 이력 조회, 로그아웃
  - **Manager 전용**: 계정 관리, 시스템 설정, 감사추적

### 4.3 로그 기록 화면 (logbook.html)
- 장비 선택 (드롭다운 목록 + 직접입력 옵션)
- 작업 시작 시간 입력 (datetime-local)
- 작업 종료 시간 입력 (datetime-local)
- 장비 사용 목적 입력 (텍스트)
- 저장 버튼 → 전자서명 (사용자ID + 저장 날짜/시간) 자동 부여
- PDF 출력 버튼

### 4.4 이력 조회 화면 (history.html)
- 필터 조건: 장비명, 날짜 범위, 작성자
- 테이블 형태로 기록 표시 (읽기 전용)
- PDF 출력 버튼 (필터링된 결과를 PDF로)

### 4.5 감사추적 화면 (audit.html) - Manager 전용
- 전체 이벤트 로그 테이블
- 이벤트 종류: 로그인, 로그아웃, 자동로그아웃, 로그 기록 작성
- 각 이벤트에 사용자ID, 발생일시 표시

### 4.6 계정 관리 화면 (admin.html) - Manager 전용
- 기존 계정 목록 표시
- 신규 Operator 계정 생성 (ID, PW, 이름)
- 계정 비활성화 기능

### 4.7 시스템 설정 화면 (settings.html) - Manager 전용
- 자동 로그아웃 시간 설정 (분 단위)
- 패스워드 정책 설정
  - 최소 길이
  - 복잡성 요건 (대소문자, 숫자, 특수문자)
  - 변경 주기 (일 단위)
- 장비 목록 관리 (추가/삭제)

## 9. 제약사항 및 참고

- **localStorage**는 브라우저별 독립 저장이므로, 다른 브라우저/PC에서는 데이터 공유 불가
- 교육/실습 목적이므로 실제 운영 환경의 보안 수준과는 차이가 있음
- 비밀번호는 단순 해시 처리 (실습 수준)
- 데이터 용량 제한: 약 5~10MB (실습 용도로 충분)
