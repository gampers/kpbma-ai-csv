# COA - 시험성적서 자동판정 시스템

**사용 목적: 시험결과 값을 입력하고 입력된 결과 값에 대한 판정결과가 자동으로 출력되어 보고서가 생성되는 시스템**

## **1 HAPPY2조 요구사항**

### 1.1. 일반 요구사항

1. 시험항목은 텍스트를 입력하는 시험항목 1개, 숫자를 입력하는 시험항목 1개가 있어야 한다.
2. 입력 결과 값은 소수점 둘째자리까지이며, 입력된 결과값 대하여 소수점 첫째짜리까지 나타내며, 둘째자리에서 반올림 한다.
3. 입력 후 판정된(출력된) 결과 값을 수정할 수 없어야 한다.
4. 보고서가 출력할때 사용자가 출력한 시간 날짜가 표시되어야 한다.

### 1.2 보안 요구사항

1. 로그인 기능이 있어야 한다. (ID/PW 입력)
2. 자동 로그아웃 기능이 있어야 하며 설정 탭에서 자동로그아웃 시간을 설정할 수 있다.

### 1.3 Audit Trail

1. 사용자 행위, 시간, 변경 내용이 남아야 한다.
2. 감사추적이력을 수정 및 삭제할 수 없다. (감사추적이력은 CSV 파일로 일단 생성)

# **2. 1조 요구사항**

### 2.1 로그인 기능

- pw 마스킹 처리가 되어야 한다.

### 2.2 결과값 입력

* 실제 결과값과 출력된 결과값의 일치 여부 확인이 가능하여야 한다.
* 시험의 허용기준을 설정할 수 있어야 한다.
* 부적합시 사유를 입력할 수 있어야 한다.

### 2.3 저장기능

* 보고서를 저장할 수 있어야 하며, 저장경로를 지정할 수 있어야 한다.
