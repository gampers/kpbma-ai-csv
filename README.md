# ㈜갬프연구소 CSV 실습 자료 통합 포털 (Vite + Vanilla JS)

본 프로젝트는 제약바이오 분야의 컴퓨터화 시스템 밸리데이션(CSV) 및 데이터 완전성(DI) 평가 기준을 직접 경험할 수 있도록 설계된 교육 실습용 통합 포털 시스템입니다.

## 🚀 주요 기능
* **6대 GMP 핵심 실습 모듈 통합**:
  1. **[COA] 시험성적서 발행**: 시험 결과 입력, 자동 판정 및 이원화 전자서명 날인, 성적서 PDF 출력
  2. **[LM] 교육 이수 관리**: 교육 이수 기록 등록, 자동 합격 판정 및 이수증 출력
  3. **[ELB] 전자로그북**: 기기/장비의 Append-only 기반 사용 기록 로깅 및 통제
  4. **[RIM] 시약/표준품 관리**: 시약 입출고 정보, 음수 재고 방지 및 유효기간 추적
  5. **[SEM] 공급업체 평가**: 협력업체 평가 점수 자동 등급 계산 및 ASL 관리
  6. **[CVM] 세척 검증 결과**: 포인트별 다항목 AND 적격 판정 및 검증서 출력
* **ALCOA+ 규제 요건 실현**:
  * 데이터 위변조 차단 및 이중 전자서명 검증 (21 CFR Part 11 준수)
  * 수정/삭제 시 사유 입력 의무화 및 감사추적(Audit Trail) 동적 다차원 필터링 구현
* **Local-First & Background Sync**:
  * 구글 스프레드시트 데이터베이스(Apps Script Web App)와 연동하여 실시간 백그라운드 동기화 수행

## 📂 폴더 구조
* `src/`: 실제 작동하는 프론트엔드 소스 코드
  * `coa/`, `modules/`: 각 GMP 실습 모듈 소스 코드
  * `shared/`: 공통 스타일(`css/common.css`), 인증 및 DB 연동 스크립트(`js/`)
* `index.html`: 단일 페이지 애플리케이션(SPA) 진입 파일
* `vite.config.js`: Vite 번들러 구성 파일
* `reference_and_backups/`: 기획안, 기존 구버전 소스 및 기획 문서 보관소 (Git 커밋 무시 영역)

## 💻 실행 방법
1. **패키지 설치**:
   ```bash
   npm install
   ```
2. **로컬 개발 서버 실행**:
   ```bash
   npm run dev
   ```
3. **프로덕션 빌드**:
   ```bash
   npm run build
   ```
